---
title: Infobox test vault
---

This vault is the content source for the local Quartz site. A note grows an infobox in the right sidebar only when its frontmatter contains an `infobox` object, using the same shape as [Omni Infobox](https://github.com/omni-gh549/obsidian-infobox).

- [[Albert Einstein]] has a gallery, tags, sections, wikilinks, and a headed list
- [[Mondstadt]] uses one image and falls back to the note's tags
- [[Hidden tags]] sets `showTags: false`
- [[Plain note]] has no infobox, so the sidebar stays empty of a card
